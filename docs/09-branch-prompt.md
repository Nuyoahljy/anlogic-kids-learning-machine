## 启动提示

你负责 `<task-id>`，只在 `<absolute-worktree>` 的 `task/<task-id>` 工作。先读本机根 AGENTS、README、FILE_INDEX、相关最新批次及本仓库规则、总记忆、计划、任务、决策、接口、任务卡和自己的日志。

目标：`<一个可独立验收的目标>`。

批准策略：`<PolicyRef>`；差异基线：`<BaseBranch>`。
允许修改：`<已批准精确路径/目录>`；禁止修改总文档、其他任务、冻结接口和范围外文件。
验收：`<实际可运行检查、预期结果及必须提交的证据>`。
停止条件：需要改接口、碰到其他写入者、需要硬件/主干操作、证据矛盾或依赖不足时先报告，不扩大任务。

每个有明确目的的变动批次更新自己的日志，新增本机共享 JSON 并刷新/校验 FILE_INDEX。不能伪造时间、测试或上板结论。工具输出独立目录，记录完整命令和退出码。

## 完成回复

- 状态：等待主对话审核 / 阻塞。
- 工作目录、分支、提交号。
- 修改文件与实际完成内容。
- 执行过的命令、退出码、证据路径/哈希及检查层级。
- 未测试事项、失败、风险和待决策项。
- 共享登记批次与索引检查结果。
- 下一步建议，不自动合并 main、烧录或清理 Worktree。
