# 系统架构

## 1. 总体数据流

```text
SC500CS
  |
  | MIPI CSI-2, RAW10, 2 lane
  v
MIPI/CSI 解包与同步
  |
  v
ISP 与 RAW10 转 RGB888
  |
  +------------------------------+
  |                              |
  v                              v
DDR2 写帧缓存                 视觉处理 Tap
  |                              |
  |                              v
  |                    颜色/投影/形状/模板检测
  |                              |
  |                              v
  |                    debounce 与 item_id
  |                              |
  +---------------+--------------+
                  |
                  v
             OSD 合成与叠加
                  |
                  v
              HDMI/TMDS 输出

FPGA 状态机
  |-- 按键消抖
  |-- 模式与计分
  |-- DFPlayer UART
  `-- 音频事件映射
```

## 2. 模块划分

| 模块 | 职责 | 输入 | 输出 |
|---|---|---|---|
| `mipi_capture` | 摄像头配置、CSI 解包、像素对齐 | MIPI 差分信号 | RAW10 像素流 |
| `isp_rgb` | 黑电平、去马赛克或简化转换 | RAW10 | RGB888 |
| `frame_buffer` | 写入/读出 DDR2 帧缓存 | RGB888 | 显示 RGB 流 |
| `vision_tap` | 降采样到约 320x180 | RGB888 + 行列同步 | 低分辨率像素 |
| `vision_detector` | 颜色、形状、卡片检测和稳定滤波 | 低分辨率像素 | `detection_result_t` |
| `osd_renderer` | Logo、检测框、文字、模式、分数、延迟 | 检测结果与状态 | OSD 像素和 alpha |
| `display_mixer` | 视频与 OSD 合成 | 视频 RGB + OSD | HDMI RGB |
| `hdmi_tx` | TMDS 编码和时序输出 | HDMI RGB + 同步 | HDMI 信号 |
| `control_fsm` | 待机、探索、问答和计分 | 按键、检测结果 | 模式、分数、音频事件 |
| `audio_uart` | 向 DFPlayer 发送控制帧 | 音频事件 | UART TX |
| `debug_uart` | 可选调试数据输出 | 检测与状态 | UART TX |

## 3. 时钟域

实际名称以官方工程为准，逻辑上分为：

- MIPI 接收时钟域。
- 像素处理时钟域。
- DDR2 控制器时钟域。
- HDMI 像素时钟域，1280x720@60 约为 74.25 MHz。
- UART 低速控制时钟域。

跨时钟域只通过同步器、异步 FIFO 或双口缓存传递，不能用普通寄存器跨域采样。

## 4. 视觉算法

### 4.1 中心识别区

- 全画面只保留中央区域用于识别。
- 原始画面映射到约 320x180 的内部坐标。
- 识别框和检测结果按比例映射回 1280x720 显示坐标。
- 推荐识别区约为低分辨率坐标的 `x=80..239`、`y=30..149`。

### 4.2 积木检测

1. RGB 转简化 HSV 或使用归一化 RGB 阈值。
2. 分别生成红、黄、蓝颜色 mask。
3. 对 mask 统计像素数、min/max X/Y、行列投影和四角占用率。
4. 用包围盒宽高比、填充率、中心列宽度和角度特征区分圆、方、三角。
5. 以连续 5 帧一致结果作为稳定结果。
6. 没有足够颜色像素时输出 `det_valid=0`。

初始形状特征：

| 形状 | 预期特征 |
|---|---|
| 方形 | 包围盒接近正方形，填充率高，四角占用明显 |
| 圆形 | 包围盒接近正方形，填充率约 0.75 至 0.85，四角占用低 |
| 三角形 | 顶部行宽小，底部行宽大，质心偏下，填充率约 0.5 至 0.65 |

阈值必须通过实测图像调整，不能把文档中的初始值视为最终值。

### 4.3 卡片检测

- 对中心识别区内的低分辨率灰度图执行归一化相关或二进制模板匹配。
- 每种卡片保存 1 个或少量模板，模板和阈值由 `learning-assets` 提供。
- 先比较轮廓或边缘，再比较内部特征，减少背景和光照影响。
- 只有最佳匹配分数超过阈值并且领先第二候选一定差值时才输出结果。

### 4.4 稳定和去重

- `stable_count` 连续增加，达到阈值后更新有效结果。
- 目标消失若干帧后才清除 `det_valid`。
- `control_fsm` 以 `(item_present, item_id)` 的边沿触发语音，避免每帧重复播放。

## 5. 错误和恢复

| 异常 | 行为 |
|---|---|
| 摄像头无输入 | 输出测试图案或提示画面，保持 HDMI 时序 |
| DDR2 写满或读空 | 使用帧有效标志保护，不显示未完成帧 |
| 检测无目标 | `det_valid=0`，OSD 显示等待提示 |
| 模板不确定 | 不更新对象，保持上一个稳定结果或显示“无法识别” |
| 按键抖动 | 消抖后仅输出一周期脉冲 |
| DFPlayer 无响应 | 不影响视频和识别，OSD 可显示音频状态 |

## 6. 资源控制

- 不在全分辨率像素流上做大型连通域和复杂模板。
- 降采样模块尽早降低数据量。
- 行投影和列投影使用小型片内 RAM。
- 模板保存在 ROM 或 BRAM 中，不占用 DDR2 带宽。
- 每个里程碑检查 LUT、DFF、ERAM、DSP 和最大时钟频率。
