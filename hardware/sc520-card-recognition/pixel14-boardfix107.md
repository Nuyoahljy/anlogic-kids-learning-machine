## 三行数字

全部为十六进制。`E/H/F/C/R/I/L/Y/A` 记录最近完成或被拒绝的一帧，`N/G` 是累计计数；16 位累计数会回绕。上电尚未收到诊断时可能短暂显示 `D0000`。

```text
D0107 Ehhhh Hhhhh Fhhhh Bhh
Chhhhh Rhhhhh Ihhhhh
Lhhhh Yhhhh Ahhhhhh Nhhhh Ghhhh
```

| 字段 | 含义与正常参考 |
|---|---|
| D | 本版标识，应为 0107 |
| E | 错误位图；完整健康帧为 0000，多项故障可同时置位 |
| H | 本帧最长 RAW 长包 HS 有效拍数；720p 候选接受 0323～0333，即 803～819 拍 |
| F | CSI EOF 解码时的 HS 状态；最高位表示当时 HS 仍高，低 15 位为当时已计数拍数；8003 一类值本身不是错误 |
| C | CSI 32 位字数；完整 720p 为 46500，即 288000 |
| R / I | RAW / ISP 四像素组数；各为 38400，即 230400 |
| L / Y | RAW 长包数 / ISP 完整行数；各为 02D0，即 720 |
| A | 最近一帧关闭时的采集时钟计数，不是毫秒 |
| N / G | 真实 CSI 帧开始累计数 / 健康完成累计数；用两张照片检查是否增加 |
| B | 显示域业务状态位图，见下表 |

`E` 位图：0001 配置未完成；0002 I2C 配置错误；0004 lane 错误；0008 帧开始重叠；0010 长包长度/顺序；0020 HS 长度越界；0040 CSI 数据数量/顺序；0080 RAW 开始/数量；0100 CSI EOF；0200 RAW EOF；0400 ISP 开始；0800 ISP 数量/EOL；1000 关闭结构；2000 超时；4000 孤立标记。

`B` 位图：01 曾收到业务观察事件；02 当前观察健康；04 最近观察冲突；08 业务超时；10 清除隔离中；20 业务跨时钟链路故障；40 曾收到诊断包；80 诊断链路故障。各位可组合；01/40 是复位后历史状态，不能单凭它们判断此刻仍在更新。

## 修复范围与限制

最终软件回读含6类测试的18轮正常/注错/提前结束资格。6轮正常合计121场景、1,917,079检查、0错；6轮真实输出注错分别检出1错、native exit1，6轮500ns提前结束分别native exit2/done0。完整pipeline几何为1280×720。最终provenance补测46场景/443检查，覆盖ISP先排空、EOF的16拍HS尾期间不提前done及退出后恰好一次完成。当前源、全部运行输入/输出、1284项原保护文件及870项历史证据重新核对通过，原v3保留。

长包仍核对声明字数、CSI/RAW/ISP 总数和行数，但允许长度下限之后最多 16 拍的 HS 尾部。EOF 短包可在 HS 仍高时解码，最终完成等待 HS 退出与 ISP 排空。16 拍为待实测确认的工程容限，不是 CSI 标准上限。

厂商接口没有 CRC/ECC 数值校验。这里只检查 HS 窗口最小长度；尾字补足缺失 CRC 占位，甚至替代尾部有效数据时，可能满足数量检查。因此不能称为通用截短/CRC 错误检测。诊断用于定位帧结构和业务拒识，不提高任意物体识别准确率。

新增组合测试已实际观察：缺CRC加1/2尾字会通过；缺1个载荷字并加1/2尾字会通过，独立载荷比较检出1个CSI字不一致；载荷字与CRC均缺时，0/1尾字被拒、2尾字可通过。此为明确保留的检查能力边界，未把它包装为鲁棒性通过。
