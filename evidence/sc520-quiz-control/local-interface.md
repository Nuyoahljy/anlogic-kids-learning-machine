# SC520 问答局部接口与行为

状态：软件候选，待主对话审核；不修改共享 `docs/03-interface-contracts.md`。模块位于 `fpga/custom_project/sc520-quiz-control/`，没有引用或改动旧视频工程。模块用可综合寄存器、计数器和有限FIFO编写；本轮验证范围为 RTL 仿真，不包含 TD 综合、资源/时序或硬件验收。

## 基本规则

| 项目 | 本次实现 |
|---|---|
| 模式 | 0待机、1探索、2问答；mode键循环切换；待机不自动切换 |
| 对象 | 1红圆、2红方、3红三角、4黄圆、5黄方、6黄三角、7蓝圆、8蓝方、9蓝三角；0及10..15不作答 |
| 每轮 | 10题；预设目标1、2、3、4、5、6、7、8、9、1；`item_for_question` 函数集中维护题序 |
| 正确 | 每题加1，进入正确反馈，之后下一题；范围0..10 |
| 错误 | 不扣分；第一次提示再试，第二次显示目标答案后下一题；`MAX_WRONG=2` 可改1..15 |
| 反馈停留 | 至少 `FEEDBACK_TICKS=1500` 个独立毫秒tick，且音频队列已空或已故障；错误重试后仍要重新移走再放入 |
| 结束 | 完成/跳过第10题后保留题号、最后目标和总分，phase=3；不自动开启新一轮 |
| 跳题 | 问答等待/反馈期间可跳当前题，不新增分数；已得的分保留；取消旧音频，再请求新题/结束提示 |
| 重播 | 等待作答时重播当前题，不清分/重置移走资格；反馈和结束期间忽略；探索重播当前有效名称 |
| 清分/退出 | reset键清分、回待机、取消旧音频；mode从问答回待机保留最后分数，下一次进入问答才清零 |

10题和正确加1、错误重试/连续错揭示来自产品规格。固定题序、第二次错、1500ms、探索进入后也要求新移走、退出保分属于本任务局部决策，修改后需重跑相应用例。

## 检测与时钟输入

`quiz_control` 的所有输入在同一 `clk` 域。`rst_n` 异步拉低复位，释放须在未来包装层同步。`tick_1ms` 为每毫秒一个时钟脉冲，**不依赖视频是否继续输出帧**；本任务由测试台提供，正式顶层须由连续运行的时钟分频生成。没有时钟域跨越包装。

| 输入 | 含义 |
|---|---|
| sample_valid | 完整检测样本的一拍使能；同一稳定物体持续存在也必须持续采样，不能只发类别改变脉冲 |
| det_present | 独立存在证据，不能用det_valid代替；未知形状、抖动、换色时仍应保持有物体 |
| det_stable、det_item[3:0] | 该样本稳定分类及既定对象编号；仅存在且稳定且编号1..9可答 |
| source_test | 1为内置测试源；必须随样本一起锁存/跨域，不能硬接0来伪装测试像素 |
| key_mode/replay/skip/reset_pulse | 四个高有效内部单周期操作，无真实GPIO绑定 |
| audio_idle、audio_fault | 来自本任务队列，决定反馈何时可前进，不决定答案是否正确 |

在探索/问答等待期间连续 `ABSENT_SAMPLES=3` 个 `sample_valid && !det_present && !det_stable && !source_test` 才置 `armed`。sample之间的无使能空拍不计数。存在但未知会打断空计数，不能把不稳定识别当移走；`det_present=0,det_stable=1` 的矛盾输入也不能计为空或作答。空场后的首次未知物体可以在稍后稳定后作答；已经答过的物体即使变为另一颜色/形状也不能重复。

进入模式、新题、反馈结束重试以及接收任意测试源样本均清除资格。题目切换时旧物体必须再次被确认移走。测试源可显示对象但不能自动计分，切回摄像来源还需3个可信空样本。测试台用source_test=0模拟摄像结果，只验证这项逻辑隔离，不证明实物识别。

旧学习wrapper可读出 `det_present || candidate_valid` 作为存在证据的候选来源，但不能直接接入宣称完成：必须确认帧对齐、稳定器丢失延迟和真正空场能否与未知区别。若上游把连续未知也报告不存在，下游无从知道物体还在，需先修上游接口/证据。

## 输出与显示

| 输出 | 定义 |
|---|---|
| mode[1:0] | 0/1/2模式 |
| phase[1:0] | 0非问答、1等待答案、2反馈、3一轮结束 |
| score[3:0] | 0..10；只在正确答案事件时加1 |
| question_index[3:0] | 问答1..10；非问答0 |
| target_item[3:0] | 当前正确目标；非问答0；用于题目/揭示答案，不能冒充检测结果 |
| quiz_active | 问答且尚未一轮结束 |
| answer_valid、answer_correct | 一拍答案事件及正误；无事件时correct=0 |
| feedback[2:0] | 0无、1正确、2再试一次、3揭示答案 |
| display_item、display_source_test | 最新样本有效对象及来源；未知/空/非法项清对象为0，独立于target |
| armed | 已确认移走，可接受首次稳定放入 |

页面预览由实际CSV逐采样驱动，独立于旧HDMI字模；题目、当前检测、反馈、分数与来源分别显示。它验证状态到显示文案的映射，没有像素级OSD时序或板上显示证据。

## 同拍优先级

硬复位 > 清分键 > mode键 > 有效skip键 > pending新题/清分音频 > replay键 > 新答案。反馈状态的replay被忽略但毫秒计时继续。mode/skip/clear同拍样本不会判答；来源与显示仍可更新。问答replay与稳定放入同拍先发题目，该物体未被消费，后续稳定样本仍可答（所以sample必须周期输出）。探索replay与首次稳定放入合并为一个名称并消耗资格；同拍新合法样本优先于旧display_item，未知样本不会重播旧项。

清分/mode/skip产生 `audio_cancel`，该拍不产生新audio_event；下一拍才输出新的题目/结束/清分提示，避免被取消吞掉。连续控制键可以继续取消尚未发送的pending提示，以最终有效状态为准。

## 音频连接及故障

连接 `quiz_control.audio_event_valid/kind/item` 到 `quiz_audio_queue.event_valid/kind/item`，`audio_cancel` 到 `cancel`，队列 `idle/fault` 返回控制器；共享同一clk、rst_n、tick_1ms。队列端口及19项专用测试见 [音频说明](audio-notes.md)。

| kind | 本地语义 | 未来逻辑素材候选（非实际文件寻址） |
|---:|---|---|
| 1 | 名称/探索重播 | item1..9 |
| 2 | 当前题目/题目重播 | 100+item |
| 3 | 正确提示 | 201 |
| 4 | 错误提示 | 202（揭示时屏幕同时给目标；无需臆造新录音） |
| 6 | 清分提示 | 206 |
| 7 | 结束提示 | 207 |

kind7是局部扩展，共享契约仍保留；重播已按上下文解析为kind1/2，不发送共享kind5，也不借用播放器“重播上一曲”。这些差异需主对话审核。题目可以未播完就接受答案，但FIFO保证先题目、后正误提示；反馈状态等队列处理完再进入下一题。重播逐次入FIFO，不使用探索旧模块的最新覆盖策略。

最多8项待播+1项活动。req_valid/req_ready与tag表示接受请求；rsp_code0仅真实曲终，1仅明确未执行拒绝，2仅ACK，3仅取消完成。ACK或BUSY下降不会推进队列。迟到/错误tag忽略，明确拒绝只重试一次；ready/busy卡死、曲终丢失、取消无响应及溢出均有界进入fault。正常完成/握手优先于超时边界；模式取消又优先于接受，取消中可排新题但未确认停止前不发送。

默认等待1000ms、播放15000ms、停止1000ms为局部上限，需按实际音频时长调整。fault锁存后丢弃后续音频，idle=1让答题和显示继续，**不表示真实设备已停止或出声成功**。清分键不恢复音频故障，必须控制器+适配器共同复位且清除迟到响应。16位tag不能跨65536事务回绕还保留旧响应；适配器必须保证响应寿命/隔离。若实际模块不能提供曲终、停止确认或明确拒绝，需提交降级语义，不能伪造这些输入。

## 按键及接入边界

`quiz_key_debounce` 高有效 `key_async` 经两级同步，按下和释放均连续20ms后才改变 `key_level`；按下仅一次 `key_pulse`。默认CLOCK_HZ=50MHz，DEBOUNCE_CYCLES=1000000，可为不同控制时钟重算。复位释放时一直按住的键，在完整确认窗口后产生一次按下。四键可各实例化一个。原板载两键仍是增益减/增，未修改其使用。

下一阶段需要真实播放器资料、同步复位/CDC、周期存在采样、四个按钮物理极性/引脚、独立毫秒时基及视频OSD包装。真实语音、实物准确率、九组合放入/移走、30分钟/2小时稳定性均须另验。本任务不提供可下载的新bit。
