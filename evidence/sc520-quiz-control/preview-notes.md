# 按键与显示预览说明

负责人：本任务协作子代理 `/root/preview_keys`。状态：实现完成，实际仿真与预览核验结果由本任务统一 `run-report.md`、运行清单及分支日志记录。2026-10-06，Asia/Shanghai。

## 按键接口

`quiz_key_debounce` 的输入为 `clk`、异步低有效复位 `rst_n`、高有效 `key_async`；输出 `key_level` 为消抖后的稳定电平，`key_pulse` 为按下确认时的单周期脉冲。高有效是局部内部约定，尚无物理按键、极性或引脚绑定，原两个板载增益按键保持原用途。

默认参数 `CLOCK_HZ=50000000`、`DEBOUNCE_MS=20`，计算得 `DEBOUNCE_CYCLES=1000000`。先经过两级寄存器同步，再连续采到指定数量的相反电平才改变稳定状态；任何返回原稳定电平的样本都会清除连续计数。按下与释放都经过消抖，稳定释放才允许下一次按下；持续按住不重复。`DEBOUNCE_CYCLES` 可覆写用于小参数仿真。参数应设置为实际时钟与至少一个资格周期；小于一周期的覆写会钳位为一周期。

原始输入在时钟边沿之前稳定时，默认在第 1000002 个采样沿确认，含两级同步延迟。复位清除稳定电平、脉冲和计数；若复位解除时仍按住，仍需完整同步与消抖后产生一次按下事件。这是本任务局部约定，最终复位释放同步与 CDC / 引脚约束由硬件包装层审核。

`tb_quiz_key_debounce` 覆盖短抖动、长抖动串、门限前后、持续按住、短释放、稳定释放、再次按下、快速反转及复位时按住。另有一个无参数覆写实例，实际运行默认 100 万样本门限。`+NEGATIVE` 仅把预期按下次数从 3 故意改为 4，以证明检查器能报错；不能计为正常功能通过。测试输出 `SUMMARY checks=... errors=... presses=... default_presses=...`，提供 `test_done` / `errors` / `checks`，自动 `$finish`；统一脚本应执行 `run -all` 并传播 `errors` 为非零退出码。看门狗为 25 ms 仿真时间。

## 离线显示预览

脚本为 `fpga/scripts/sc520-quiz-control/render-preview.py`，仅依赖 Python 标准库。用实际完成的集成仿真 CSV 调用：

```powershell
python fpga/scripts/sc520-quiz-control/render-preview.py --trace <actual-run>/trace.csv --output <actual-run>/display-preview.html
```

输入列：`cycle,mode,phase,question,target,score,feedback,item,source_test,armed,audio_fault,answer_valid,answer_correct`，均为十进制整数。模式 `0=待机,1=探索,2=问答`；阶段 `0=闲,1=等待答案,2=反馈,3=本轮结束`；反馈 `0=无,1=正确,2=再试一次,3=揭示答案`。题号非问答可为 0，问答时为 1..10。对象 1..9 沿用产品规格九色形组合；0 显示未知/无目标，10..15 显示本任务不支持项。

生成前验证非空数据、字段完整整数、周期递增、score 0..10、问答题号 1..10、模式/阶段/反馈/对象范围与布尔字段，并拒绝 `source_test && answer_valid`。这属于显示证据的输入合法性检查，不替代 RTL 测试台的计分与时间行为检查。非法输入退出 1；合法输入退出 0。输入 CSV 不会被修改；输出路径不可等于 CSV。

页面内嵌实际 trace 数据，不联网、不播放声音。包含当前题目、目标与输入图形、正误/揭示反馈、0..10 分数、输入来源、答案脉冲、移走后允许作答状态、音频故障、逐采样时间轴与关键状态跳转。代表卡片最多显示 24 个首次状态组合，全部记录仍在时间轴中可访问。页面给出实际 CSV 绝对路径、SHA-256、样本数与答案事件数，便于与运行清单对照。

标题和提示明确写“RTL 仿真预览 · 音频模拟”；所有非测试来源输入仍标“模拟摄像输入”，测试来源标“测试来源 · 禁止正式计分”。此页面与旧视频链完全独立，不是 HDL 字模/HDMI 像素验证，不代表实物识别或实际出声。真实 OSD、四键 IO、同步约束及播放器接入另行验证。
