## SRAM 验证

1. 用 TD Programmer 的 `PROGRAM_SRAM` 加载本 bit；本版本尚未上板验证，不写 Flash。
2. 先保持 SW4 为 0，完成初次校准，确认现有卡片/几何识别、跟踪、四键业务、风格切换和 TF 语音正常。
3. 换光源后将 SW4 从 0 稳定拨到 1。观察校准期间识别撤销、画面持续输出，重新锁定后识别恢复；持续为 1 不应反复触发。
4. 先拨回 0 再拨到 1，重复一次。记录有无卡死、旧识别残留、颜色不恢复或语音异常。

真实摄像头色彩、完整 720p/CSI/DDR 与实板稳定性仍需此轮验证。回退对照使用既有 [I0309](../sc520-i0309/README.md)；旧 I0310R3 再校准失败历史保留。
